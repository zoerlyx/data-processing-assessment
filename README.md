# Coding Camp - Data Processing & ETL Pipeline Assignment

This repository contains the learning assignments and implementation for the Data Processing module in the Coding Camp program, focusing on building an ETL (Extract, Transform, Load) pipeline, web scraping, and database automation.

## 🛠️ Prerequisites & Dependencies

This project requires Python and the following packages:

- `pandas==2.2.3`
- `requests==2.32.3`
- `beautifulsoup4==4.12.3`
- `sqlalchemy==2.0.36`
- `psycopg2-binary==2.9.10`
- `gspread==6.1.4`
- `google-auth==2.36.0`
- `pytest==8.3.3`
- `python-dotenv==1.0.1`
- `pytest-cov==5.0.0`
- `coverage==7.13.5`

## 🚀 How to Run

### 1. Run the ETL Pipeline Script
```bash
python3 main.py
```

### 2. Run Unit Tests

Execute unit tests located in the tests folder:

```bash
python3 -m pytest tests
```
### 3. Run Test Coverage

Measure test coverage for the test suite:

```bash
coverage run -m pytest tests
```
